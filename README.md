## Sobre a SouCodigo

A SouCodigo é uma organização de projetos colaborativos que aproxima pessoas desenvolvedoras, designers e profissionais de diferentes áreas para criar soluções com propósito. O trabalho é liderado por [Beatriz Karoline](https://github.com/SouBeatrizKaroline).

## Como colaborar

1. Escolha um projeto e consulte o README do repositório.
2. Abra uma issue descrevendo a melhoria, dúvida ou problema.
3. Crie uma branch com uma mudança pequena e objetiva.
4. Envie um pull request explicando o que mudou e como validar.

Contribuições em código, design, documentação, testes e acessibilidade são bem-vindas.

## Princípios

- **Impacto social:** tecnologia deve ampliar oportunidades.
- **Inclusão:** diferentes experiências tornam os projetos melhores.
- **Aprendizagem aberta:** compartilhar conhecimento faz parte do processo.
- **Colaboração respeitosa:** ideias são discutidas com empatia e clareza.
